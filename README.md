# Desafío Sistemas USS 🎮

Juego estudiantil para que chicos de 15 y 16 años descubran la carrera de **Ingeniería de Sistemas e Informática**.

- Cartas **¿Sí o No?** contra el reloj: ¿un ingeniero de sistemas puede hacer esto?
- **3 vidas** hasta el primer jefe; después, un solo error termina el juego.
- **Peleas contra jefes** (← → moverse, ↑ saltar, ESPACIO atacar, SHIFT esquivar, K súper). En celular, con botones en pantalla.
- **Ranking** en cada dispositivo.

Hecho solo con HTML, CSS y JavaScript. Para jugar, abre `index.html` o la versión publicada en GitHub Pages.

> Proyecto estudiantil de Ingeniería de Sistemas e Informática · USS. No es una página oficial de la universidad.
